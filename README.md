# Situacions d’aprenentatge de Matemàtiques ESO

## Font d’impressió

Aquesta versió deixa **Times New Roman** com a font predeterminada per imprimir i exportar a PDF, perquè en les proves evita el problema visual de la lletra “l”.

Es manté Arial com a opció secundària, però la recomanació és usar Times New Roman.

## Correccions mantingudes

- Selector de font visible.
- Botó “Exportar PDF corregit”.
- Rúbrica amb columnes correctes:
  - Ítem
  - Criteris
  - NA
  - AS
  - AN
  - AE
